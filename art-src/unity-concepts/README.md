# Unity art direction exploration

Generated concept images, not screenshots of the Unity implementation.
Created with the built-in imagegen tool using the existing Drifter character as an identity reference.

- `a-chunky-3d.png`: rounded, chunky stylized 3D; simple matte materials.
- `b-painterly-storybook.png`: hand-painted surfaces, softer storybook atmosphere.
- `c-moody-fantasy.png`: more angular forms, textured stone, dramatic lighting.

All three explore the same snowy dungeon encounter, ice sword slash, gremlin, charger, and extraction doorway. Art direction remains open for iteration. No Tripo credits were used.
